Social Media Campaign Performance Tracker

This project is an interactive Power BI dashboard designed to analyze and visualize Facebook social media campaign performance.

🔍 Key Objectives
	•	Track overall Ad Spend, Impressions, Clicks, and ROI
	•	Compare ad spend across different campaigns
	•	Identify high-performing and low-performing campaigns
	•	Support data-driven marketing decisions

📈 Key Features
	•	KPI cards for quick performance overview
	•	Campaign-wise ad spend analysis
	•	ROI visualization using gauge charts
	•	Interactive filtering for better insights
	•	Clean and professional dashboard layout

🛠 Tools & Technologies
	•	Power BI
	•	Facebook Ads dataset
	•	Data modeling & DAX measures

🎯 Outcome
The dashboard helps marketers understand how effectively ad budgets are converted into results and highlights areas for optimization.
